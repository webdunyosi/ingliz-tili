## ✨ Loyihaning Asosiy Xususiyatlari

Loyiha foydalanuvchini jalb qilish va yuqori konversiyani ta'minlash uchun eng so'nggi dizayn trendlari va texnologiyalaridan foydalangan holda yaratilgan:

*   **✨ Glassmorphism & Neon Dizayn**: Zamonaviy oynasimon interfeys, yarim shaffof elementlar va nozik gradientlar (Blue & Purple).
*   **🌌 Interaktiv Zarralar (Particles.js)**: Orqa fonda sichqoncha harakatiga javob beruvchi interaktiv va dinamik zarralar effekti.
*   **📐 3D Tilt Effekti (Vanilla-Tilt)**: Statistika kartalari ustiga sichqoncha olib borilganda real 3D burilish effekti.
*   **🎬 Video Darslar**: Bepul YouTube video darslar joylangan interaktiv bo'lim.
*   **📈 Jonli Statistika**: Sahifa ochilganda yoki unga scroll qilinganda noldan boshlab animatsiya bilan o'suvchi raqamli hisoblagichlar.
*   **📱 To'liq Responsive (Moslashuvchan)**: Barcha turdagi qurilmalar (smartfon, planshet, noutbuk) uchun mukammal moslashgan maket.
*   **📞 Aloqa kartasi va Jonli Soat**: Foydalanuvchi bilan bog'lanish uchun doimiy faol aloqa bloki va real vaqtda yangilanuvchi o'zbekcha elektron soat.
*   **🧭 Scroll-Progress & Smooth Navigation**: Foydalanuvchining sahifadagi joylashuvini ko'rsatuvchi yuqori progress-bar va silliq scroll animatsiyasi.

## 🛠️ Texnologik Stack

Loyihada quyidagi texnologiyalar va kutubxonalardan foydalanilgan:

| Texnologiya / Kutubxona | Vazifasi / Maqsadi |
| :--- | :--- |
| **HTML5** | Sahifaning semantik va qulay tuzilishi |
| **Tailwind CSS v4** | Yuqori darajadagi zamonaviy va tezkor stillash tizimi |
| **Vanilla CSS** | Qo'shimcha murakkab animatsiyalar va noiz effekti uchun |
| **Particles.js** | Orqa fondagi dinamik interaktiv zarralar uchun |
| **Vanilla-Tilt.js** | Elementlarning 3D burilish (tilt) effekti uchun |
| **AOS (Animate On Scroll)** | Sahifa skroll qilinganda elementlarning chiroyli paydo bo'lishi uchun |
| **JavaScript (ES6+)** | Dinamik hisoblagichlar, jonli soat, progress-bar va boshqa mantiqlar uchun |

## 🚀 Mahalliy Tizimda Ishga Tushirish

Loyihani o'zingizning kompyuteringizda ishga tushirish uchun quyidagi oddiy qadamlarni bajaring:

### 1. Loyihani yuklab oling yoki klonlang
```bash
git clone https://github.com/o'z-profilingiz/ingliz-tili-kurs.git
cd ingliz-tili-kurs
```

### 2. Dependency-larni o'rnating (agar kerak bo'lsa)
```bash
npm install
```

### 3. Brauzerda oching
Loyiha sof HTML/CSS/JS dan iborat bo'lganligi sababli, `index.html` faylini to'g'ridan-to'g'ri istalgan brauzerda ochib ko'rishingiz yoki VS Code'dagi **Live Server** kengaytmasidan foydalanishingiz mumkin.
